# Chinois en Devenir

Next.js 16 app for [chinoisendevenir.com](https://chinoisendevenir.com) — study-in-China guidance, student space, and admin CRM.

```bash
npm install
npm run dev
npm test
```

Required env (see `.env.example`): `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`, `SUPABASE_SERVICE_ROLE_KEY`, `RESEND_API_KEY`.
